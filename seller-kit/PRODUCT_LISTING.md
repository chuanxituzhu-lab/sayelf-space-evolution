# 小红书商品页文案（¥19.9 首发版）

## 商品名
**线落成墙｜AI 空间生成 Skill v1.0**

## 一句话卖点
上传一张手绘稿，让 AI 保持同一个空间，从草图一直长成墙、空间和视频。

## 核心差异
普通做法：草图 → 一张效果图。

本产品：
**手绘稿 → 草图整理 → 线落成墙 → 空间成型 → 视频分镜**

核心规则：**变的是完成度，不变的是空间。**

## 你会获得
- 本地 WebUI 工作台
- 手绘稿录入
- 空间一致性锁
- 三阶段图片提示词
- 视频分镜提示词
- Skill 文件
- Agent 执行规范
- 示例工程
- 安装与故障排查说明

## 电脑要求
Windows/macOS/Linux；推荐 Python 3.10+。Windows 双击启动文件即可运行，无需额外安装 Python 第三方依赖。

## 重要说明
本商品不包含第三方 AI 平台会员、API Key 或生成额度。图片/视频的实际生成，需要使用你已有权限的 AI 图像/视频工具。
