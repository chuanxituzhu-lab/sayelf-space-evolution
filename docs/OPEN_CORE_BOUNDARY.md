# Open Core Boundary

## Public repository

This repository is the public MIT Core for Sayelf Space Evolution. It contains the local-first workflow, Canonical Space Schema, explicit Drawing/Sketch intake, Spatial Engineering Lock, Native Provider, tests, and sanitized examples.

The root `LICENSE` is the public software license for this Core. The public repository does not contain customer data, credentials, private Provider implementations, or private commercial delivery materials.

## Commercial Pro

Commercial Pro is maintained in a separate private repository or as separately licensed private modules. It may consume the MIT Core and add professional adapters, enterprise deployment, private templates/assets, customer-specific rules, support, training, and SLA-backed delivery.

Pro code, customer content, private adapters, credentials, and unpublished business materials must not be copied into this public repository. A commercial contract governs Pro deliverables separately.

## Version boundary

The current public branch is the MIT Core line. Existing public history may contain earlier commercial packaging files; deleting those files from the current branch clarifies the current boundary but does not rewrite history.
