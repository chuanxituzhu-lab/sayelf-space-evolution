# 购买后请先看这里

你购买的是一个本地运行的 AI 空间演化工作流产品，不是某一家图像模型的会员或 API 额度。

## 购买后你可以
- 在自己电脑启动 WebUI
- 上传手绘稿
- 自动生成空间一致性约束
- 获取草图、线落成墙、空间成型、视频四阶段提示词
- 把结果交给你已有权限的 AI 图像/视频平台使用
- 导出项目工作流并长期复用

## 购买后你不需要
- 注册本产品账号
- 上传项目到本产品服务器
- 为本产品额外购买 Token

## 如果要一键出图/出视频
需要额外接入支持 API 的图像/视频 Provider。Provider 费用与账号由对应第三方平台收取，本产品 v1.0 默认不代购、不包含。
